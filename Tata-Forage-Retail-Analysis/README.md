Tata Forage Retail Analysis – Power BI

Project Overview
This project was completed as part of the Tata Data Visualization Virtual Experience Program on Forage.

The objective of the project was to analyse online retail data and generate business insights for the CEO and CMO using Power BI dashboards.

Key Tasks Performed
- Data Cleaning and Transformation
- Revenue Analysis
- Customer Analysis
- Country-wise Revenue Analysis
- Product Demand Analysis
- Dashboard Development

Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

Business Insights
The analysis identified strong seasonal revenue trends, top-performing international markets, high-value customers, and regions with strong product demand to support expansion decisions.
