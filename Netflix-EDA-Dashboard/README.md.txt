Netflix Data Cleaning & Exploratory Data Analysis (EDA) Dashboard

Project Overview
This project focuses on performing Data Cleaning, Exploratory Data Analysis (EDA), and Dashboard Development using the Netflix Movies and TV Shows dataset from Kaggle.
The objective was to analyze Netflix's content library and uncover trends related to content types, ratings, release years, and country-wise distribution through an interactive Power BI dashboard.

Project Objectives

- Clean and transform raw Netflix data
- Explore content distribution across multiple dimensions
- Identify trends in Netflix's content growth
- Analyze content ratings and classifications
- Examine country-wise content availability
- Develop an interactive dashboard for data storytelling

Dataset Source: Netflix Movies and TV Shows Dataset (Kaggle)

The dataset contains information such as:

- Title
- Type (Movie / TV Show)
- Rating
- Country
- Release Year
- Duration
- Genre Information
- Description

Data Cleaning & Transformation

The following preprocessing steps were performed using Power Query:

- Handled missing values
- Standardized data formats
- Removed inconsistencies
- Created additional analytical fields
- Prepared data for visualization and reporting

Exploratory Data Analysis

The dashboard explores:

Content Type Analysis
- Distribution of Movies and TV Shows

Rating Analysis
- Most common content ratings on Netflix

Country Analysis
- Top countries contributing content

Release Year Analysis
- Growth of Netflix content over time

Interesting Words Analysis
- Frequency analysis based on selected keywords

Dashboard Features

- Interactive Filters and Slicers
- Country-wise Content Analysis
- Rating Distribution Visualization
- Release Year Trend Analysis
- Content Type Breakdown
- Business-Oriented Dashboard Layout

Tools & Technologies

- Power BI
- Power Query
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization

Key Insights

- Movies represent the majority of Netflix content.
- TV-MA is the most common content rating.
- Netflix experienced significant content growth after 2015.
- The United States contributes the highest number of titles.
- Content production increased rapidly during the streaming expansion period.
